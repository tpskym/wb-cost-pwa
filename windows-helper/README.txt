Компонент «Мастерская»: Windows 10/11

1. Распакуйте архив полностью в любую папку.
2. Запустите Install.cmd. Выберите ТУ ЖЕ папку, что указана кнопкой «Папка label / model» в Мастерской.
   Не нужны права администратора, Node.js, Python или расширение браузера.
3. В Windows назначьте Bambu Studio приложением по умолчанию для .3mf/.stl,
   Foxit Reader — для .pdf (Параметры → Приложения → Приложения по умолчанию).
4. В Мастерской откройте «Бэкап» → «Открывать в Windows», включите «Компонент Windows установлен».
5. Скачайте модель или этикетку кнопкой Мастерской. В появившемся окне нажмите «Открыть в Windows».
   Браузер может спросить разрешение открыть Windows PowerShell — это установленный компонент.
   Нажмите «Открыть». Автоматически подтвердить этот запрос сайт не может.

Компонент открывает только label.pdf и model.3mf/.stl/.step/.stp/.obj/.gcode
из выбранной вами папки. Ничего не отправляет в сеть и не меняет файлы.
Не работает с «(1)», «(2)»: используйте рабочую папку и сохранение с заменой в Chrome/Edge.
При смене рабочей папки повторите Install.cmd и выберите новую папку.
Снятие галочки в Мастерской возвращает браузерный просмотр.
Для удаления запустите Uninstall.cmd. Модели и этикетки сохранятся.

Установка регистрирует workshop-files:// только для текущего пользователя
и сохраняет скрипт и путь к папке в %LOCALAPPDATA%\WorkshopFileOpener.
Архив с установкой можно удалить после установки.
