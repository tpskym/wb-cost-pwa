Мастерская — компонент macOS (Apple Silicon и Intel)

1. Распакуйте архив и откройте «Установка Мастерской.app».
   Если macOS блокирует загруженное приложение без нотариального заверения Apple:
   попробуйте открыть его, затем Системные настройки → Конфиденциальность и безопасность → Всё равно открыть.
   Не отключайте защиту macOS. Установка не требует прав администратора.
2. Выберите ту же папку, что указана в Мастерской кнопкой «Папка label / model».
3. В Мастерской → Бэкап включите «Компонент установлен».
4. Сохраните модель или этикетку. В окне нажмите «Открыть на Mac».
   Браузер может запросить разрешение открыть Workshop File Opener — подтвердите.

Для модели: Finder → Свойства файла → Открывать в программе → Bambu Studio → Настроить всё.
Для PDF аналогично выберите Foxit, Просмотр или другую программу.
Используйте Chrome/Edge с рабочей папкой: Safari не предоставляет сайту запись с заменой в выбранную папку.
После смены рабочей папки повторите установку.

Компонент создаётся локально встроенным osacompile в ~/Applications/Workshop File Opener.app.
Путь к папке: ~/Library/Application Support/WorkshopFileOpener/folder.txt.
В фоне ничего не работает, сеть не используется. Допустимы только label.pdf и model.* стандартных форматов.
Для удаления переместите Workshop File Opener.app из вашей папки Applications в Корзину
и удалите папку ~/Library/Application Support/WorkshopFileOpener. Сами модели и PDF не удаляются.
Снимите галочку «Компонент установлен» в Мастерской, чтобы вернуть просмотр в браузере.
