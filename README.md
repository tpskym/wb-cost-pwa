# WB Cost PWA

PWA для расчёта себестоимости товаров и прибыльности продаж на Wildberries.

## Статус

Сбор требований. Реализация приложения ещё не начата.

## Подтверждённые решения

- Формат приложения: PWA.
- Использование на macOS и Windows.
- Исходный код — в публичном репозитории GitHub.
- Назначение — расчёт себестоимости товаров для карточек Wildberries.
- Первый сценарий — собственное производство на 3D-принтере, затем добавление автозапчастей.
- Полная экономика товара с видимыми показателями и расшифровкой затрат.
- Начальный налоговый профиль НПД; поддержка смены режима с сохранением истории.
- Первая версия: WB со своего склада (FBS), ручной ввод данных, Bambu Lab P2S Combo и PLA.
- Далее — склад WB и Ozon с отдельными сценариями продаж для одного товара.
- Один пользователь, один Google-аккаунт; синхронизация через общий файл Google Drive с полной загрузкой базы при переходе между Mac и Windows.

Подробности: [черновик требований](docs/requirements.md).

В репозитории размещаются код и документация. Реальные данные продавца, токены WB, ключи SSH и пароли не включаются.
